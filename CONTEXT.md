# Paste

A macOS menu bar app that lets a person attach their own text to a key combination, so pressing that combination types the text for them.

## Language

**Binding**:
A key combination linked to a piece of text. Pressing the combination produces the text.
_Avoid_: Shortcut, hotkey, macro, mapping

**Combo**:
The key combination a person chooses for a Binding, such as Command+V or Command+Shift+L.
_Avoid_: Shortcut, hotkey, keystroke

**Text**:
The plain text a Binding produces, such as a postal code or a LinkedIn URL.
_Avoid_: Snippet, payload, value, link

**Pause**:
The master switch that stops every Binding from producing Text, so the keys behave normally again.
_Avoid_: Disable all, kill switch
